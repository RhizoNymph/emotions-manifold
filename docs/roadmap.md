# Manifold Emotions — Project Roadmap

## Goal

Extend Goodfire's manifold steering framework
(`papers/markdown/ManifoldSteering/`) to operate over the multi-dimensional
emotion-concept manifold identified by Anthropic
(`papers/markdown/EmotionVectors/`). Concretely: fit an activation
manifold M_h and behavior manifold M_y over emotion concepts in an open
model, test the isometry M_h ↔ M_y, and run geometry-aware steering
(manifold + pullback) against linear steering as the baseline.

## Why this combination

- Goodfire validated their manifold-steering framework on 1D conceptual
  spaces (days, months, letters, ages) and a 2D in-context-learned grid.
  They explicitly flagged emotions, refusals, and sycophancy as the
  natural next step. Their parameterizations (1D cubic splines, 2D
  thin-plate splines) won't carry over directly — emotions are higher
  intrinsic dimension, plausibly stratified by cluster, and the domain
  is not a clean Cartesian product.
- Anthropic produced 171 emotion vectors with rich geometric structure
  (PC1 ≈ valence, PC2 ≈ arousal, ~10 k-means clusters, orthogonal
  present-speaker / other-speaker subspaces). They observed that linear
  steering exhibits the exact pathology Goodfire's framework predicts:
  e.g. "steering positively with both happy and sad vectors decreases
  blackmail rate" — two opposite linear steers cutting through
  off-manifold regions.

Anthropic supplies the labeled centroids. Goodfire supplies the
geometry-aware intervention framework. The project is to bridge them.

## Stack

We use the custom vLLM fork documented in:

- `docs/capture_consumers.md` — pluggable residual-stream activation
  capture, filesystem consumer streams `.bin` + sidecar JSON per request
- `docs/steering.md` — three-tier per-request steering (base / prefill /
  decode) at `pre_attn` / `post_attn` / `post_mlp` hook points, binary
  wire format on the OpenAI-compatible HTTP path, named-module
  pre-registration. Gemma 4 is in the supported architecture list.

All extraction and steering runs go through the OpenAI-compatible HTTP
endpoint with an async client, so the engine's continuous batching stays
saturated while orchestration (story generation, judging, manifold
fitting) runs in separate processes.

## Constraints to respect

- **`tensor_parallel_size = 1`** for any extraction phase: the
  filesystem capture consumer rejects TP>1. Steering itself supports TP,
  but we keep extraction single-GPU.
- **Bump `--max-steering-configs`** for Phase 5 to fit the number of
  distinct manifold waypoints we want in flight per batch. Default is 4;
  we'll likely want 64+.
- **Binary wire format mandatory** for per-request steering payloads in
  Phase 5 — JSON-encoded hidden-size blobs cost ~10–15 ms per request
  per the docs. Named modules are an even tighter alternative: register
  the K=50 waypoints once, reference by name.
- **Activations stay bf16** under 4-bit weight quantization — quant
  affects weights only, residual stream is computed in bf16. Geometry
  should survive; calibrate steering strengths against actual residual
  norms on a neutral dataset before drawing absolute comparisons.

## Phases

Phases map 1:1 onto the tasks in TaskList (#1–#9). Each phase has a gate
criterion; do not advance past a failing gate.

### Phase 0 — Setup (Task #1)

Locked parameters:

- **Model:** `unsloth/gemma-4-31B-it-GGUF` (GGUF format)
- **Target layer:** 40 of 60 (exactly 2/3 through, matching Anthropic's
  "about two-thirds" choice)
- **Hook point:** `post_mlp`
- **LLM judge:** Claude API (Sonnet 4.7, latest at project start)
- **Tensor parallelism:** TP=1 (required by filesystem capture consumer)

Risk noted: GGUF in vLLM is experimental in mainline; the custom fork
may or may not have it wired for Gemma 4 specifically. First probe is
to verify the fork can load the model and round-trip a capture request.
If GGUF doesn't work, fall back to AWQ or bf16.

**Gate:** model loads under the vLLM fork at GGUF; capture consumer
round-trips a smoke-test request and writes a valid `.bin` + sidecar
pair.

### Phase 1 — Story corpus (Task #2)

Generate emotion-conditioned stories, the substrate for diff-in-means
extraction. Anthropic used 171 emotions × ~12 stories × ~100 topics
(~205k stories). We start small to shake out the pipeline:

- **Shakedown:** 30 emotions × 50 stories × 1 topic (~1500 stories)
- **Full:** 171 emotions × full topic sweep, once the small run is clean

Store as JSONL with `(emotion_label, topic, text)` per row. Stories can
be generated by the Gemma instance itself or by the LLM judge model.

**Gate:** spot-check N=30 stories per a sample of emotions confirms the
intended emotional content is present.

### Phase 2 — Activation extraction (Task #3)

Stream residual-stream activations through the filesystem capture
consumer. Per-request capture spec:

```python
SamplingParams(
    max_tokens=1,
    capture={"filesystem": FilesystemCaptureRequest(
        request_id=f"{emotion}_{topic}_{story_idx}",
        tag=emotion_label,
        hooks={"post_mlp": [TARGET_LAYER]},
        positions="all_prompt",
    )},
)
```

Fire requests via async HTTP client with bounded concurrency (e.g.
`Semaphore(64)`). Captured `.bin` files land under
`{root}/{emotion_slug}/{request_id_slug}/{layer}_post_mlp.bin`. Skip
tokens before index 50 in the post-processing pass per Anthropic.

**Gate:** all stories have a corresponding `.bin` written; capture
results report `status == "ok"`.

### Phase 3 — Emotion vectors + validation (Task #4)

Offline pass over saved activations:

1. Per-emotion centroid: mean over all post-index-50 tokens across all
   stories for that emotion
2. Diff-in-means: emotion centroid minus global mean centroid
3. Denoise: project out top PCs (50% variance) of a neutral-text
   dataset, per Anthropic
4. Stored as a `(num_emotions, hidden_size)` array with a label index

Validation must all pass before continuing:

- PCA over the 171 vectors yields a valence-like PC1 and arousal-like
  PC2 / PC3, correlating with LLM-judged valence/arousal scores
- Logit lens through the unembed upweights emotion-related tokens
  ("happy" → "excited", "celebrating"; "sad" → "grief", "tears")
- Max-activating examples on a held-out corpus (Common Corpus, LMSYS,
  etc.) look semantically correct
- If quantized: cross-check ~10 vectors against an fp16 extraction;
  pairwise cosine similarity should exceed ~0.95

**Gate:** all four validation checks pass on the shakedown corpus
before scaling to the full 171 × full topic sweep.

### Phase 4a — Activation manifold M_h (Task #5)

Fit a parameterization or metric over the 171 validated emotion
centroids in a PCA-reduced subspace (64-D, following Goodfire).

**Primary approach: density geometry G_E (Goodfire Eq. 6).** Fit an
energy / log-density model E(h) over the centroids — small EBM,
score-matching network, or even a Gaussian mixture with shared
covariance. Geodesics under G_E(h) = (α e^{−E(h)} + β)^{−1} I_n are
computed by path optimization. Sidesteps the "what are the intrinsic
coordinates" question, which is the hardest part for emotions.

**Secondary approach (interpretable comparison): circumplex trunk +
per-cluster fibers.** 2D tensor-product cubic spline over (valence,
arousal) through the cluster centroids, plus per-cluster local splines
for within-cluster offsets, stitched with a partition-of-unity blend.
Matches the qualitative geometry Anthropic describes and gives clean
intrinsic coordinates.

**Out-of-scope but noted:** GPLVM / Riemannian normalizing flow for
fully unsupervised manifold learning, diffusion maps for intrinsic
coordinate discovery. Revisit if the two primary approaches both fail.

**Gate:** geodesics between any two emotion centroids are computable
and qualitatively sensible (e.g. a path from "calm" to "anxious"
passes through low-arousal-to-high-arousal intermediates, not through
"joyful").

### Phase 4b — Behavior manifold M_y (Task #6)

Run in parallel with 4a. For each emotion centroid:

1. Sample N continuations from a held-out neutral-prompt set (no
   steering applied — the prompt itself conditions the model toward
   the emotion context)
2. Score each continuation with the LLM judge on (valence, arousal,
   dominant-cluster)
3. Behavior centroid = mean / distribution in this output-emotion-space

Map onto Hellinger coords (per Goodfire §2.2) if fitting a smooth
surface; for a continuous valence/arousal space we may use the squared
distribution directly without the simplex mapping.

**Gate:** behavior centroids cluster in valence/arousal space in a
pattern that visually mirrors the activation centroids' PCA layout.

### Phase 5 — Isometry check (Task #7)

The load-bearing empirical question. Compute pairwise geodesic
distances on M_h and on M_y across all emotion pairs:

- d_h(i,j) — geodesic distance on M_h
- d_y(i,j) — geodesic distance on M_y
- d_lin(i,j) — linear (Euclidean) distance in activation space, as
  baseline

Compute Pearson correlation r(d_h, d_y) and r(d_lin, d_y). Goodfire saw
r≈0.99 on simpler concepts; for emotions, r above ~0.7 would be
encouraging. Also compute an MDS embedding of each distance matrix and
inspect visually.

**Gate (critical project decision point):**

- If r(d_h, d_y) is high → proceed to Phase 6 with confidence the
  manifold view is the right frame
- If r(d_h, d_y) is moderate but r(d_lin, d_y) is much lower → still
  proceed; the geometry helps, even if imperfectly
- If r(d_h, d_y) ≈ r(d_lin, d_y) → the emotion manifold likely lives
  in a subspace conditioned on speaker (present/other) or layer
  (sensory/action). Revisit Phase 2–4 with sliced data before steering
  experiments. This is a real possibility given Anthropic's orthogonal
  speaker subspaces.

### Phase 6 — Manifold vs linear steering (Task #8)

Goodfire §3.2 protocol applied to emotion pairs. For each chosen pair
(happy↔sad, calm↔desperate, anger↔calm, etc.):

1. Compute K=50 waypoints along the geodesic on M_h
2. Pre-register each waypoint as a named steering module in vLLM
3. For each waypoint, generate N continuations from a held-out prompt
   set with `steering_name` referencing that waypoint, applied to
   `post_mlp` at the target layer
4. Judge each continuation's emotion content (valence, arousal, top
   cluster)
5. Compare against:
   - **Linear baseline:** K=50 waypoints from straight-line
     interpolation between the endpoint emotion vectors
   - **No steering baseline:** continuations under the prompt alone

Quantify with:

- Cumulative Bhattacharyya energy against M_y (Goodfire Eq. 3)
- Smoothness of the behavioral trajectory (no teleportation between
  non-adjacent emotion clusters)
- Naturalness of generated text (perplexity under the unsteered model,
  qualitative inspection)

**Alignment-relevant probe:** does manifold steering avoid the "two
opposite linear steers both decrease blackmail rate" pathology
Anthropic reported? Run a small blackmail / sycophancy eval at the
midpoint of a happy↔sad manifold geodesic vs. its linear counterpart.

**Gate:** manifold steering produces measurably more natural behavior
trajectories than linear, with the effect statistically significant
across emotion pairs.

### Phase 7 — Pullback steering (Task #9)

Goodfire §3.3 protocol. Optimize activation-space paths to induce paths
along M_y, measure whether the optimized trajectories recover M_h
(intrinsic R² as Goodfire defines it).

This is a stretch goal — only meaningful if Phase 5 and 6 produced
clean results. The interpretability payoff is the bidirectional
M_h ↔ M_y story; the practical payoff is an alternative steering
strategy that may handle cases where M_h is hard to parameterize
directly.

## Manifold parameterization candidates (Phase 4a detail)

In rough order of preference:

1. **Energy-based density geometry (G_E).** Primary path. No explicit
   parameterization needed.
2. **Hierarchical circumplex + fibers.** Most interpretable. Tensor-
   product cubic spline trunk + per-cluster local splines.
3. **Tensor-product B-splines in 3-4 intrinsic dims.** Add a continuous
   cluster coordinate. Tractable up to ~4 dims.
4. **Riemannian GPLVM.** Unsupervised; addresses Goodfire's stated
   limitation about needing labeled intrinsic coordinates.
5. **Diffusion maps + RBF/TPS interpolant.** Decouples "find intrinsic
   coords" from "fit smooth surface."

We start with (1), add (2) for interpretability comparison, and reach
for (3)–(5) only if both fail.

## Open subtleties to revisit at later phases

- **Locality of emotion representations.** Anthropic shows the vectors
  track the *operative* emotion at a token, not a persistent character
  state. A single-token geodesic intervention may not install a
  persistent emotional state across a conversation. If Phase 6 shows
  the behavioral effect doesn't persist past the first few tokens, we
  may need to extend steering across many decode positions (the
  decode-tier steering vector path supports this).
- **Present-speaker vs other-speaker subspaces.** Nearly orthogonal in
  Anthropic's data. Manifold-steering on M_present should leave
  M_other-projected activations near-stationary; linear steering with
  the same overall norm will bleed into both. This is a clean side
  experiment if Phase 5 isometry holds.
- **Layer-wise geometry.** Early-mid layers encode "sensory" emotion
  content; mid-late encode "action" / planned emotion. We fit at one
  layer in Phase 4a. If the geometry differs sharply across layers,
  the manifold may need to be a fibration over layer index.
